# 검색 노출(SEO) 정리 계획

dfch.org 연결(2026-10-12) 뒤 검색엔진이 사이트를 제대로 읽고, "드림숲교회"·"군포 교회" 같은 검색에 잘 나오게 한다.

## 지금 상태 (2026-10-13 운영 사이트 조회)

- 있음: robots.txt(관리자·/r2/ 제외), 글 본문 페이지별 제목·미리보기(`src/lib/postMetadata.ts`), 주보는 일부러 검색 제외(`src/lib/noSearch.ts`), `lang="ko"`.
- 없음: 사이트맵(`/sitemap.xml` 404), 페이지별 제목·설명(목록·안내 12쪽이 모두 "드림숲교회"), 대표 주소(canonical), `dfch.vercel.app` 중복, 교회 정보 구조화 데이터, 구글·네이버 등록.
- 설명 문구가 예전 표현("나눔이 섬김이 되는")으로 남아 있음.

## 설계

- **제목 규칙**: 레이아웃에 `title: { default, template: "%s | 드림숲교회" }`. 하위 페이지는 메뉴 이름(`src/lib/nav.ts`)을 제목으로 쓴다. 글 본문은 `postMetadata`가 지금 붙이는 `| 드림숲교회`를 빼서 두 번 붙지 않게 한다.
- **공용 함수**: `src/lib/pageMetadata.ts`에 `pageMetadata(path, description)` — 메뉴 이름으로 제목, 경로로 대표 주소(`alternates.canonical`)를 만든다. 페이지는 `export const metadata = pageMetadata("/about", "…")` 한 줄.
- **사이트맵**: `src/app/sitemap.ts`. 고정 페이지 + 공지·묵상·목회편지·갤러리 글(`getAllPosts`에서 주보·배너 제외), `lastModified`는 글 수정일. 새 글이 들어오도록 1시간마다 다시 만든다(`revalidate = 3600`). 주소는 `SITE_URL` 기준.
- **robots**: 정적 `robots.txt`를 `src/app/robots.ts`로 바꿔 같은 규칙에 `Sitemap: https://dfch.org/sitemap.xml`을 더한다.
- **주소 하나로**: `next.config.ts`의 `redirects()`에서 호스트가 `dfch.vercel.app`이면 같은 경로의 `https://dfch.org`로 308 넘김. 미리보기 배포 주소는 그대로 둔다.
- **교회 정보**: 메인에 JSON-LD 한 덩어리 — `Church`(이름, 주소, 전화, 로고, 유튜브 `sameAs`)와 `WebSite`(사이트 이름). 값은 `src/lib/site.ts`에서 가져온다.
- **소유 확인**: 구글은 Cloudflare DNS TXT(도메인 전체 확인, 코드 배포 필요 없음), 네이버는 레이아웃 `verification.other["naver-site-verification"]` 메타 태그.
