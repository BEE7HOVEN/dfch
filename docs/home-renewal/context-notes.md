# 메인 첫 화면 개편 결정 기록

## 출발점 (2026-10-04)
- 사용자가 우리들교회(woori.cc) 메인처럼 "왼쪽 광고 배너 + 오른쪽 설교 카드" 구성을 제안. 구성 아이디어만 참고하고 디자인은 현재 사이트의 차분한 회색 톤에 맞춘다.
- 사용자 결정: 화면 전체 교회 사진 슬라이드를 배너+설교 카드 줄로 **교체**, 배너는 **관리자 화면에서 올림**, 맨 위 한 줄 알림 띠는 **넣지 않음**(아래 최근 공지 칸과 겹침).

## 설계
- **배너는 `posts`(분류 `banner`) + 첨부 사진.** 게시 시작일은 기존 `post_date`, 링크와 종료일은 `posts`에 빈 칸 두 개(`link_url`, `ends_on`)를 추가해 저장. 별도 표를 만드는 것보다 기존 관리자 작성·수정·삭제·첨부 흐름을 그대로 쓸 수 있다.
- **보여 줄 배너**: 시작일 ≤ 오늘(한국 시간) 이고 종료일이 없거나 오늘 이후. 메인은 5분 재검증이라 종료 반영은 최대 5분 늦을 수 있다.
- **포스터 잘림 방지**: 세로 포스터가 많을 것이라 `object-contain`으로 전체를 보이고, 같은 사진을 흐리게 깔아 빈 곳을 채운다.
- **배너 사진 주소**: 메인 HTML이 캐시되므로 서명 주소 대신 고정 주소 `/r2/banner/...` 사용(갤러리 표지와 같은 이유).
- **배너가 없을 때**: 기존 교회 사진(hero-1~9)을 같은 자리에 넘겨 보여 준다(문구 없음).
- **설교 카드**: 기존 `/api/youtube`(Edge, 1시간 캐시)를 브라우저에서 불러 최신 주일설교를 보여 준다.

## 진행 중 사용자 요청으로 바뀐 것
- 첫 화면의 교회 사진 위 문구 "말씀이 삶이 되고 / 나눔이 섬김이 되는 공동체"는 **뺀다**.
- 교회 건물 사진 슬라이드는 없애지 않고 **크게(화면 폭 전체) 유지하되 배너·설교 줄 아래**로 옮긴다(`HeroSlideshow`, 높이 모바일 56vh·PC 78vh).
- 배너가 하나도 없을 때 왼쪽 칸에도 교회 사진이 나오므로 바로 아래 큰 사진과 겹쳐 보일 수 있다. 행사 배너를 걸어 두는 것을 전제로 하고, 필요하면 다른 기본 이미지로 바꾼다.

## 함께 고친 문제
- `<form action={formAction}>`으로 두면 React 19가 저장 동작 뒤 폼을 자동 초기화해, 검증 오류 때 입력한 제목 등이 사라졌다(목회편지부터 있던 문제). `onSubmit`에서 `startTransition(() => formAction(formData))`로 직접 제출하도록 바꿔 오류 때도 입력이 남는 것을 확인.
