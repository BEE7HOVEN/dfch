# 디자인 개편 결정 기록

## 출발점 (2026-10-04)
기능을 하나씩 붙이며 홈페이지가 어수선해짐. 원인: 폭이 제각각(3xl·5xl·6xl 혼재), 제목 규칙 없음, 글꼴(영문 Quicksand + 기기 한글)·색(회색 2개) 미정리, 메인 흐름 없음.

## 우리들교회(woori.cc)에서 확인한 것
- 콘텐츠 폭 `.hr-shell { width: min(1440px, 100% - 80px) }`, 1200px 이하 `100% - 48px`, 767px 이하 `100% - 36px`.
- 첫 줄 그리드: 배너 + 설교 카드(남색, 모서리 24px), 간격 24px, 높이 약 430px.
- 칸 제목: 작은 영문 이름표(QUICK ACCESS, THIS WEEK, WORD & WORSHIP …) + 큰 한글 제목 + 오른쪽 설명/전체보기.
- 하위 페이지: 사진 띠 없이 경로(홈 › 예배와 말씀 › 주보 › 금주의주보) + 왼쪽 큰 제목.
- 주보 목록: 표지 카드 3열. 주보 본문: 문서 보기 창(확대·축소·쪽 이동·PDF 저장·전체화면·인쇄) + 이전·다음·목록.
- 글꼴 Noto Sans KR, 본문 색 #222.

## 사용자 결정
- 포인트 색 깊은 숲 초록, 하위 페이지 머리는 경로 + 큰 제목, 큰 건물 사진은 교회 소개와 함께 아래쪽, 주보는 한 쪽씩 넘겨 보기.

## 우리 쪽 결정
- 글꼴은 Pretendard(한글 가독성 좋고 무료, 필요한 글자만 받는 jsDelivr 동적 분할판). next/font 자체 호스팅 대신 CDN 링크를 쓴 이유: 가변 글꼴 전체(약 2MB)를 내려받지 않고 글자 범위별로 필요한 것만 받기 위함.
- 넓은 폭은 바둑판·목록에만 쓰고, 긴 글은 읽기 폭(약 760px)으로 가운데 둔다. 1440px 줄글은 읽기 어렵다.
- `Shell` 컴포넌트 대신 Tailwind `@utility shell`(CSS)로 폭 규칙을 둠. 감싸는 요소 하나 늘리지 않고 클래스만 붙이면 돼서 더 단순.
- 머리글은 고정 위치라, 머리글 컴포넌트가 자기 높이(72px)만큼 빈 칸을 함께 둔다. 페이지마다 있던 `pt-16`은 일괄 삭제.
- 개발 서버가 `globals.css`를 바꿔도 옛 CSS를 계속 내보낸 적이 있음(Turbopack 캐시). `.next/dev`를 지우고 다시 켜서 해결. 빌드 결과물에는 문제없었음.
- 메인 교회 소개 칸은 사진 위에 글을 얹으므로 좌우 화살표가 글과 겹쳐 숨기고 점 표시만 둠. 휴대폰 영상 카드는 6개 → 3개.
- 머리글 개편(사용자 요청 "작고 밋밋함"): 높이 72 → PC 88px·휴대폰 68px, 로고 150px. PC 메뉴는 1024px(lg) 이상에서만 펼치고, 그 아래는 메뉴판 버튼. 하위 메뉴는 메뉴마다 따로 뜨는 작은 상자 대신, 메뉴 줄에 올리면 세 묶음이 한 번에 펼쳐지는 넓은 메뉴판(상위 메뉴와 같은 열 폭 `w-[156px] xl:w-[176px]`이라 세로줄이 맞음). 지금 있는 메뉴는 초록 밑줄·굵게, 내리면 그림자. 휴대폰 메뉴판은 오른쪽에서 밀려 들어오는 움직임 추가.
- 칸 제목 문구가 우리들교회 것을 그대로 따라 해 바꿈(사용자 선택 "숲 묶음", 이름표는 한글). 바로가기 "어서 오세요, 드림숲입니다"(처음 고른 "숲으로 들어오는 길"은 사용자가 별로라 해 교체), 이번 주 "이번 주, 숲에서 들려온 소식", 말씀과 예배 "한 절씩, 말씀 따라 걷는 길", 갤러리 "숲에서 함께한 날들", 교회 소개 "말씀으로 함께 자라는 숲". 영어 이름표(Quick Access 등)는 한글로, 카드 안 영어 이름표(WELCOME·WEEKLY BULLETIN·SUNDAY MESSAGE)는 바로 옆 한글 제목과 겹쳐 지움.
- 사용자가 "숲" 비유 문구를 별로라 해 다시 바꿈. 갤러리 "우리가 함께한 자리", 이번 주 "이번 주 드림숲 소식", 교회 소개 "한 절이라도 따라 사는 교회". 남은 "숲" 비유 문구 없음.
- 설교말씀이 적게 나온 원인: 유튜브 공개 피드(RSS)는 최신 15개만 준다(주일설교 5·수요설교 4). 유튜브 데이터 API(playlistItems, 채널 업로드 재생목록 `UU…`, 50개씩, 호출 1번에 할당량 1)로 전체를 받고, 키(`YOUTUBE_API_KEY`)가 없거나 실패하면 RSS로 돌아간다. 응답은 1시간 CDN 캐시라 하루 할당량(10,000)에 한참 못 미친다.
- 설교말씀 탭·쪽은 클라이언트 상태 대신 주소(`/media?tab=sunday&page=2`)에 둔다. 뒤로 가기·공유가 되고, 영상 목록은 클라이언트 컴포넌트가 한 번만 받아 쪽 이동 때 다시 받지 않는다. 탭 목록(`src/lib/sermonTabs.ts`)은 서버 페이지도 써야 해서 클라이언트 파일 밖으로 뺐다("use client" 파일의 값은 서버에서 그대로 못 쓴다).
- 주보 넘겨 보기(`BulletinViewer`): 맞춤 상태에서는 쪽들을 옆으로 이어 붙여 translateX로 밀어 넘기고(휴대폰은 손가락 50px 이상 밀면), 확대하면 지금 쪽만 크게 띄워 스크롤한다. 지금 쪽과 앞뒤 쪽만 바로 불러온다. 아이폰처럼 요소 전체화면이 안 되는 곳에서는 전체화면 단추를 숨긴다.
- PDF 저장: 같은 파일에 `response-content-disposition=attachment` 서명 주소를 따로 만든다(다른 도메인이라 `<a download>`가 안 먹음). 실제 응답 헤더로 내려받기 확인.
- PDF만 올린 주보는 넘겨 보기·표지가 안 되므로, 관리자 업로드 때 브라우저에서 pdf.js(`pdfjs-dist`)로 쪽마다 긴 변 2000px JPEG를 만들어 사진 첨부로도 올린다(PDF 원본은 저장용으로 그대로). 서버 변환 대신 브라우저 변환을 고른 이유: Vercel 함수 용량·시간 제한과 4.5MB 요청 한도를 피하고, 기존 사진 업로드 흐름을 그대로 쓴다.
- pdf.js가 탭이 가려져 있으면 멈추는 문제: 화면용 그리기는 requestAnimationFrame을 기다리는데 숨은 탭에서는 오지 않는다. `intent: "print"`로 그리면 기다리지 않는다(관리자가 변환 중 다른 탭으로 가도 안전).
- 이전에 남은 PDF만 있는 주보는 PDF 열기·저장 단추로 보여 준다(PC는 PDF 화면도 함께).
- 다음에 할 일 후보: 주보·설교 목록이 아주 길어지면 주보 목록에도 쪽 번호. `VideoGrid.tsx`는 어디서도 쓰지 않는 옛 파일(지우지 않고 남겨 둠).
- 머리글 색(2026-10-04): 흰 바탕 유지. 초록 머리글은 주일설교 카드·바닥글과 겹쳐 위쪽이 무겁고, 흰 로고는 원래 로고를 뒤집은 것이라 작은 글씨가 흐리며, 흰 펼침 메뉴판과 따로 놀아서. 비교 그림 `header-compare.png`(커밋 안 함).
- 초록이 너무 진하다는 의견으로 한 단계 흐리게 바꿈(사용자 선택 A안): forest #24402f→#355a44, forest-deep #1a3023→#2a4636, forest-soft #3d5e4a→#4f7560, mist #eef3ef→#eff5f1. 흰 글씨 명도 대비 초록 위 7.8·바닥글 위 10.4(기준 4.5 이상). 더 흐린 B안(#4a7059)은 바닥글이 가벼워 보여 뺌. 비교 그림 `green-compare.png`(커밋 안 함).
- 목사님 주보는 대부분 한글(HWP 5.x) 파일, A4 가로 한 장. 브라우저는 HWP를 못 열고, 서버 변환(LibreOffice+H2Orestart)은 별도 서버와 한글 글꼴이 필요해 칸이 깨지기 쉬워 하지 않음 → 한글에서 PDF로 저장해 올리도록 하고, 관리자 화면에서 HWP를 고르면 안내 문구를 띄움.
- PDF 쪽 사진: 긴 변 2400px·JPEG 0.8(일반 사진은 2000px·0.85). 9pt 글씨가 확대해도 읽히는 선이고 쪽당 약 0.7~0.8MB. 2000px보다 10%쯤 큼. pdf.js에서 PNG(무손실)로 그린 뒤 JPEG로 한 번만 압축(이전에는 JPEG→JPEG 두 번).
- 가로 주보: 휴대폰 넘겨 보기 높이를 첫 쪽 비율(aspect-ratio)에 맞춤. 두 손가락 확대 중에는 쪽을 넘기지 않음. 목록·메인 표지는 가로 쪽이면 오른쪽 기준으로 자름(접는 주보는 첫 장 오른쪽 칸이 표지).
- 주보에 헌금자 명단·투병 기도 제목·생일·계좌가 들어 있음. 공개 범위는 교회가 정할 일로 남김.
- 주보 검색 제외: 주보 목록·본문에 noindex·nofollow·noimageindex(원본 PDF 링크도 따라가지 않게), robots.txt로 /r2/(메인 주보 표지 고정 주소)·/admin 수집 막음. 카톡 공유 미리보기(og)는 그대로.
- 주보 넘김을 책장 넘김으로(사용자 요청): 라이브러리 없이 CSS 3D(rotateY, 왼쪽 모서리 축) + Web Animations API 0.7초. 넘기는 장(preserve-3d)에 투명도를 걸면 입체가 평면으로 눌려 앞면이 거꾸로 비치므로 투명도는 종이 뒷면에만 건다. 확대 중·'동작 줄이기' 기기는 효과 없이 바로 바꿈. 쪽 상자는 container query 단위(cqw·cqh)로 쪽 비율대로 맞춰 축이 쪽 모서리와 맞게 함. 쪽 양쪽 3분의 1을 누르면 넘김(가운데는 비움), 밀어서 넘긴 직후 0.4초는 누름 무시. 비교 녹화 bulletin-slide.gif·bulletin-flip.gif(커밋 안 함).
- 책장 넘김은 사용자가 별로라 해 빼고 쪽을 바로 바꿈(쪽 양쪽 누르기·밀기·단추·키보드는 유지). 공유 단추: 주보 목록 '이번 주 주보' 카드(그 주보 주소를 공유)와 넘겨 보기 도구 띠에 알약 모양으로 추가. ShareButton에 path·pill 옵션.
- 배너가 칸을 꽉 채우지 않는다는 의견: 칸은 PC 높이 480px 고정이라 화면 폭에 따라 1.3~2.1:1로 바뀜. 그림과 칸 비율 차이가 1.3배 이내면 object-cover(꽉 채움, 가장자리 조금 잘림), 더 다르면 contain+흐린 배경. 휴대폰 칸은 4:3→19:10. 권장 배너 1920×1010, 글씨는 왼쪽 190px 안쪽(1280px 화면에서 좌우 6.5%씩 잘려도 안전). 관리자 배너 양식에 권장 크기 안내.
- 관리자 글 관리를 게시판별 탭으로(?board=), 글 게시판은 표, 갤러리·주보는 표지 카드, 배너는 사진 카드+상태(게시 중·예약·내림)+내리기/다시 걸기. 내리기=종료일을 어제로, 다시 걸기=종료일 없앰 → DB 구조 변경 없이 켜고 끔. 저장·삭제 뒤에는 그 게시판 탭으로 돌아옴.
- 바로가기 강조 카드 3개를 초록에서 "처음 오셨나요?"와 같은 연한 바탕(mist)으로 힘 뺌(사용자 요청). 메인 교회 소개 제목을 교회 표어 "말씀이 삶이 되고 / 섬김이 되는 공동체"로(두 줄로 끊음).
- 메인 '이번 주' 칸: 금주의 주보를 3칸 중 2칸 너비로 넓혀 첫 쪽 전체를 원본 사진으로(가로 주보가 잘리지 않게, /r2 고정 주소에 주보 원본 허용), 오른쪽은 공지사항. 매일의 묵상은 말씀과 예배 칸의 수요설교 아래로 옮겨 최근 6개를 3칸씩(RecentMeditations 서버 컴포넌트를 WordWorship의 children으로 넣음, 유튜브 실패해도 묵상 줄은 보임). 1280px 미만에서는 주보 그림을 카드 폭 가득, 제목·단추는 아래로.
- 바로가기 카드 6장을 모두 같은 색으로 통일하고, mist가 너무 흐려 안 보인다는 의견에 한 단계 진한 sage(#e3ece6) 색 이름을 새로 둠.
- 바로가기 색이 어색하다는 의견(왼쪽 mist·오른쪽 sage, 비슷하지만 다른 초록 두 가지): 네 안 비교 뒤 사용자 선택 C안. 오른쪽 메뉴도 왼쪽과 같은 규칙(연한 초록 판 + 흰 카드)으로 맞춤. sage 색 이름은 쓰지 않아 지움. 비교 그림 quickaccess-options.png(커밋 안 함).
